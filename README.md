# Strata

*Strata* is a web app for visualising the history of websites as recorded by web archives. Using data gathered by [Pluto](https://github.com/overbrowsing/pluto), it draws every URL as a layer on a shared timeline, from its first archived capture to its last, revealing when pages appeared, how long they lasted and what survives today. Zoom from decades down to a single capture and open it as it was, in the archive that holds it.

## Usage

   1. Run [Pluto](https://github.com/overbrowsing/pluto) on the URL(s) you want to analyse

   2. Open Strata ([https://overbrowsing.com/strata](https://overbrowsing.com/strata))

   3. Click **Upload Data** and choose the folder Pluto saved your results to (`output/` by default, or wherever you pointed `--output`)
